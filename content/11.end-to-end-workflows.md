## 11.1 Main construction workflow

```text
Foundation Masters
  → Project
  → Cost Codes and Items
  → Estimate
  → Purchase Order
  → Change Order (when needed)
  → Stock Receipt Note
  → Vendor Invoice
  → Reports
```

## 11.2 Estimate to Purchase Order

1. Create and approve the project estimate.
2. Create a Material PO.
3. Select Import Items from Estimate.
4. Select available items and quantities.
5. Review remaining estimate availability.
6. Approve the PO.

## 11.3 PO/CO receiving

1. Approve the material PO or CO.
2. Open Stock Receipt Notes.
3. Select the source and lines.
4. Record Shipment or Received quantities.
5. Save.
6. Confirm the source becomes Partially Received or Completed.
7. Review Stock reports.

## 11.4 PO/CO invoicing

1. Confirm the PO/CO and vendor.
2. Create Against PO or Against CO invoice.
3. Enter remaining quantities/amounts.
4. Adjust advance and holdback.
5. Review charges, tax, and COA.
6. Verify and approve.
7. Review payment details and AP reports.
