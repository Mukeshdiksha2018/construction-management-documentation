## Purpose

A Purchase Order commits material or labor from a vendor for a project.

## Before you begin

- Project and vendor must exist.
- Required addresses and masters should be active.
- Import from Estimate requires an approved estimate.

## 6.1 Purchase Order list

**Where to go:** Const Orders → Purchase Orders

Use status, project, vendor, date, and search filters. The **To be Created** view identifies available source work that has not yet been ordered.

![Screenshot UG-PO-01 — Const Orders Purchase Orders list](/images/UG-PO-01.png)

## 6.2 Create a Purchase Order

1. Select **Add Purchase Order**.
2. Confirm corporation and project.
3. Select Material or Labor.
4. Select the vendor and vendor address.
5. Review PO number, entry date, and delivery date.
6. Select shipping/billing addresses, Ship Via, Freight, and credit days.
7. Select the item source.
8. Add or import lines.
9. Review charges, taxes, and total.
10. Add instructions, terms, attachments, and quote reference.
11. Save, verify, or approve as permitted.

![Screenshot UG-PO-02 — Create / Edit Purchase Order form](/images/UG-PO-02.png)

## 6.3 Material item sources

- **Custom:** enter lines manually.
- **Import Items from Master:** select preferred catalog items.
- **Import Items from Estimate:** select available items from the approved estimate.

When importing from an estimate, the system compares ordered quantity with remaining estimated quantity. It can block quantities above the available amount.

## 6.4 Labor POs

Select Labor, choose source cost codes, and enter labor PO amounts. Labor totals flow into the same financial summary and approval process.

## 6.5 Financial breakdown

Review:

- Item total.
- Freight, packing, custom duties, and other charges.
- Applicable tax.
- Total PO amount.

Confirm taxable selections and percentages before approval.

## 6.6 Statuses

- **Pending:** being prepared.
- **To be approved:** awaiting approval.
- **Approved:** approved for use.
- **Purchase order rejected:** returned for correction.
- **Partially Received:** some ordered material has been received.
- **Completed:** all receivable material has been fulfilled.

Receipt Notes update the last two statuses.

## 6.7 Print, email, attachments, and revision

Use Print for the formatted PO. Email sends the preview/document to recipients. Attachments retain quotations or supporting files.

Revision fields describe a change to the same PO; they do not create a separate immutable version.

## Common issues

- Estimate is not approved.
- Quantity exceeds estimate availability.
- Required vendor/project/address is missing.
- PO cannot be edited because a Receipt Note or Vendor Invoice exists.
- PO cannot be deleted because a CO, Receipt Note, or Vendor Invoice exists.
- Approved/received PO is restricted to selected updates such as Ship To or print options.
