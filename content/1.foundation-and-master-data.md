## Purpose

Foundation data supplies the choices used by Projects, Estimates, Purchase Orders, Change Orders, Receipt Notes, Vendor Invoices, and Reports.

## Recommended setup order

1. Select or create the corporation.
2. Review the Chart of Accounts.
3. Review UOM and UOM Types.
4. Review Ship Via and Freight.
5. Create Vendors.
6. Create Project Types, Terms and Conditions, and Special Instructions.
7. Create cost code divisions and configurations.

## 1.1 Corporations

**Where to go:** Nimble → Create Corporations

Corporations define the business context for projects, vendors, estimates, purchase orders, invoices, and reports.

Corporations must be created and modified from the **Create Corporations** screen in Nimble. This includes the corporation name, legal details, currency, and active status.

After the corporation is available, select it in Construction Management to work with its projects and transactions.

![Screenshot UG-COR-01 — Nimble Create Corporations screen](/images/UG-COR-01.png)

## 1.2 Chart of Accounts

**Where to go:** Nimble → Chart of Accounts

Chart of Accounts entries are assigned to cost code configurations and later used when approved vendor invoices are posted.

Chart of Accounts entries must be created and modified from the **Chart of Accounts** screen in Nimble. After an account is available, it can be selected while configuring the related cost code in Construction Management.

![Screenshot UG-COA-01 — Nimble Chart of Accounts screen](/images/UG-COA-01.png)

## 1.3 UOM and UOM Types

**Where to go:** Masters → UOM / UOM Types

Units of Measure are used on catalog items, estimates, PO/CO lines, receipts, and invoices. Examples include Each, Feet, Square Feet, Hours, or Tons.

Before deactivating a UOM, check whether it is already used on active documents.

![Screenshot UG-UOM-01 — Masters UOM screen](/images/UG-UOM-01.png)

## 1.4 Ship Via

**Where to go:** Masters → Ship Via

Ship Via identifies the shipment method or carrier. Create or modify Ship Via options from the **Ship Via** screen under Masters.

After a Ship Via option is available, it can be selected in Purchase Order and Change Order headers and shown on printed documents.

![Screenshot UG-SHV-01 — Masters Ship Via / Courier screen](/images/UG-SHV-01.png)

## 1.5 Freight

**Where to go:** Const Masters → Freight

Freight supplies the freight choices used by purchasing documents. Create or modify Freight options from the **Freight** screen under Const Masters.

After a Freight option is available, it can be selected in Purchase Order and Change Order headers and shown on printed documents.

![Screenshot UG-FRT-01 — Const Masters Freight screen](/images/UG-FRT-01.png)

## 1.6 Vendors

**Where to go:** Payables → Vendors

Vendors are required for POs, COs, Receipt Notes, and Vendor Invoices.

Typical workflow:

1. Open Vendors.
2. Search before adding to avoid a duplicate.
3. Select **Add Vendor**.
4. Enter vendor identity, address, payment, and contact details.
5. Save.
6. Confirm the vendor appears in the list and relevant selectors.

![Screenshot UG-MST-01 — Payables Vendors screen](/images/UG-MST-01.png)

## 1.7 Configurations and other masters

**Where to go:** Const Masters

Configurations include Project Types, Service Types, Terms and Conditions, and Special Instructions. Masters also include Approval Checks, PO Instructions, Charges, Sales Tax, and Reasons.

These values should be configured before users create operational documents. If a selector is empty, verify its master record is active and available in the selected corporation context.
