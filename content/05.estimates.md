## Purpose

An estimate creates the project budget by cost code, labor, material, location, and contingency.

## Before you begin

- The project must exist.
- Cost code configurations must be active.
- Item Types, Items, UOM, and locations should be ready.
- Only one active estimate is allowed per project.

## 5.1 Estimate list

**Where to go:** Projects → Estimates

Summary cards show Drafting, For Approval, and Approved totals. Search by estimate number, project, or status.

![Screenshot UG-EST-01 — Projects Estimates list](/images/UG-EST-01.png)

## 5.2 Create an estimate

1. Select **Add New Estimate**.
2. Confirm corporation.
3. Select the project.
4. Confirm the automatically assigned estimate number.
5. Select an estimate date within the project date range.
6. Add the required cost codes.
7. Enter labor and material information.
8. Review contingency and totals.
9. Save or move the estimate through the available workflow action.

If the project already has an active estimate, edit that estimate instead.

![Screenshot UG-EST-02 — Create / Edit Estimate form](/images/UG-EST-02.png)

## 5.3 Cost code lines

Each line can include:

- Labor amount.
- Material amount or material item rows.
- Location-wise labor/material when enabled.
- Contingency percentage and amount.
- Total cost for that cost code.

Labor can be entered manually, per room, per square foot, hourly, or by location.

Use **Configure Cost Codes** to add or change the cost codes on the estimate. Select a cost code row to enter or review its labor and material details.

![Screenshot UG-EST-03 — Estimate cost code lines](/images/UG-EST-03.png)

## 5.4 Workflow statuses

- **Draft:** still being prepared.
- **Ready:** submitted for approval.
- **Approved:** available for approved-budget and estimate-import purchasing workflows.
- **Rejected:** returned for correction and resubmission.

The available Save, Verify, Approve, Reject, or Update buttons depend on role and workflow level.

## 5.5 Audit history

Audit history shows who created, updated, verified, approved, or rejected the estimate.

Open the estimate and select **View Audit Log** to review that history.

![Screenshot UG-EST-04 — View Audit Log on an estimate](/images/UG-EST-04.png)

## Common issues

- **Estimate already exists:** one active estimate is allowed per project.
- **Date outside project range:** correct the estimate or project dates.
- **Cannot save zero amount:** at least one meaningful line total is required.
- **Cost code cannot be removed:** it may already be used by purchasing.
- **No Approve button:** user role or approval level does not permit it.
