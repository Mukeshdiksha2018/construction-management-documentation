## Purpose

Item Types classify material. The Items List shows the reusable preferred-item catalog created under cost code configurations.

## 4.1 Item Types

**Where to go:** Projects → Items → Item Types

To create an item type:

1. Select **Add New Item Type**.
2. Choose Procurement or Construction category.
3. Enter the Spec Type.
4. Enter the Item Type name.
5. Add a description.
6. Save.

An item type already used by items or transaction lines may not be deactivated or deleted.

![Screenshot UG-ITM-01 — Projects Item Types list](/images/UG-ITM-01.png)

## 4.2 Items List

**Where to go:** Projects → Items → Items

The list combines preferred items from cost code configurations. Columns include Project, Category, Item Type, Item Name, Unit Price, UOM, Description, and Status.

Use the project filter to focus on one project. Search can find item names, sequences, model numbers, cost codes, UOM, descriptions, and status.

![Screenshot UG-ITM-03 — Edit Item form](/images/UG-ITM-03.png)

## 4.3 Add or edit an item

1. Select **Add Item** or Edit on an existing row.
2. Confirm project, category, and item type.
3. Select the cost code.
4. Enter item name, UOM, unit price, and description.
5. Enter vendor, location, model, inventory, or reorder information if used.
6. Save.

Items referenced by estimates, POs, COs, or direct invoices cannot be deleted until those references are removed.
