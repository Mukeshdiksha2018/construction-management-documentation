## Purpose

Cost codes classify estimated and actual project costs. A configuration is the cost code selected on estimates, POs, COs, invoices, and reports.

**Where to go:** Projects → Cost Codes

Open the **Cost Codes** tab, then use **Cost Codes Division** or **Cost Codes Configuration**.

![Screenshot UG-CC-01 — Projects Cost Codes screen](/images/UG-CC-01.png)

## 3.1 Cost code divisions

**Where to go:** Projects → Cost Codes → Cost Code Divisions

Divisions group related cost codes.

To add a division:

1. Select **Add Division**.
2. Enter division number and name.
3. Set display order.
4. Add a description if needed.
5. Choose whether to exclude the division from estimates and reports.
6. Set Active and save.

Deletion can be blocked when configurations use the division.

![Screenshot UG-CC-02 — Cost Codes Division list](/images/UG-CC-02.png)

## 3.2 Cost code configurations

**Where to go:** Projects → Cost Codes → Cost Code Configurations

To create a configuration:

1. Select **Add Configuration**.
2. Choose the corporation and division.
3. Enter cost code number and name.
4. Assign the GL account.
5. Select a parent cost code when creating a hierarchy.
6. Add description and effective date if applicable.
7. Add preferred items when required.
8. Set Active and save.

![Screenshot UG-CC-03 — Cost Codes Configuration list](/images/UG-CC-03.png)

![Screenshot UG-CC-04 — Edit Cost Code Configuration form](/images/UG-CC-04.png)

## 3.3 Preferred items

Preferred items define reusable material choices under a cost code. They can carry item type, UOM, unit price, project, location, and preferred vendor.

The same items appear in the Items List and can be selected for estimates and purchase orders.

## 3.4 CSV import

The Cost Codes hub supports bulk import. Before importing:

1. Download or review the expected sample format.
2. Confirm corporation and division identifiers.
3. Remove duplicate numbers.
4. Validate GL accounts.
5. Import a small test file first.
6. Review the result before loading the full file.

## Common issues

- Duplicate division or cost code number.
- Missing GL account.
- Parent code belongs to the wrong corporation.
- Deactivation blocked because the cost code is in use.
- Delete blocked by estimates, POs, COs, or invoices.
