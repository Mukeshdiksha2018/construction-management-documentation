## Business terms

- **Corporation:** business/property context owning project data.
- **Cost Code:** classification used to budget and record project costs.
- **Preferred Item / Item Master:** reusable material catalog entry under a cost code configuration.
- **Estimate:** project budget by cost code, labor, and material.
- **PO:** Purchase Order commitment to a vendor.
- **CO:** Change Order modifying an existing PO.
- **GRN / Receipt Note:** record of material shipment or receipt.
- **Advance Payment:** payment made before later PO/CO invoice application.
- **Holdback:** retained amount withheld until later release.
- **COA:** Chart of Accounts allocation used for accounting posting.
- **UOM:** Unit of Measure.

## Workflow status comparison

| Module | Status | Meaning |
|---|---|---|
| Estimate / PO / CO | Draft | Being prepared |
| Estimate / PO / CO | Ready | Waiting for approval |
| Estimate / PO / CO | Approved | Approved for downstream use |
| Estimate / PO / CO / Invoice | Rejected | Returned for correction |
| PO / CO | Partially Received | Some receivable material fulfilled |
| PO / CO | Completed | All receivable material fulfilled |
| GRN | Shipment | Quantity is in shipment for stock reporting |
| GRN | Received | Quantity is current stock |
| Vendor Invoice | Unpaid | Posted but not paid |
| Vendor Invoice | Partially Paid | Some payment received |
| Vendor Invoice | Paid | Fully paid |
| Vendor Invoice | Void | Voided and read-only |

> GRN Shipment/Received is not the same as PO/CO Partially Received/Completed. Invoice Approved is also not the same as Paid.
