## Purpose

A project groups estimates, purchase commitments, receipts, invoices, and reports.

## Before you begin

- Select the correct corporation.
- Prepare project dates, addresses, and location breakdown.
- Confirm the Project Type exists.

## 2.1 Project list

**Where to go:** Projects → Project Details

The list provides search and status summaries such as Pending, Bidding, Started, In Progress, Completed, and On Hold.

![Screenshot UG-PRJ-01 — Projects Project Details list](/images/UG-PRJ-01.png)

## 2.2 Create a project

1. Select **Add Project**.
2. Confirm the corporation.
3. Enter the project ID and project name.
4. Select the project type and status.
5. Enter start and estimated completion dates.
6. Complete address information.
7. Enable and define location-wise structure when the project requires it.
8. Add supporting documents if needed.
9. Save.

**Expected result:** The project appears in Project Details and becomes selectable in downstream modules.

![Screenshot UG-PRJ-02 — Add New Project form](/images/UG-PRJ-02.png)

## 2.3 Location-wise projects

Location-wise tracking allows labor and material to be planned and reported by project area.

Define a consistent hierarchy before creating estimates. Changing locations after estimates or purchasing documents exist can be restricted.

## 2.4 Edit and view

- **View** shows the project without editable controls.
- **Edit** updates allowed project details.
- **Edit Locations** may be available as a limited action.

If an estimate already exists, some structural project fields may be locked to protect downstream calculations.

## Common issues

- **Project does not appear:** confirm corporation and active status.
- **Date rejected:** ensure the date is valid and the completion date is not before the start date.
- **Cannot edit:** the project may have dependent estimates or transactions.
- **Cannot delete:** active estimates, POs, COs, receipts, or invoices may reference the project.
